# Grovs Community

Grovs provides self-hosted deep linking, attribution and analytics for mobile and
web applications. The Marketplace package installs the published backend and
dashboard images with PostgreSQL, Redis, ClickHouse and background workers on
one Ubuntu 24.04 server.
