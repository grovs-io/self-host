# Deployment buttons

README buttons use a shared 200 × 56 SVG canvas, 28 × 28 logo area and fixed
text positions. Keep these dimensions when adding a platform. SVGs embed their
artwork so GitHub can display them without external image dependencies.

## Logo sources

- Docker, CapRover, Railway, Render, AWS, Google Cloud, DigitalOcean, Hetzner,
  Vultr, Akamai and Scaleway: [Simple Icons](https://simpleicons.org/) via
  React Icons 5.5.0, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- Coolify: Simple Icons artwork reused from the Grovs documentation site.
- Azure: Microsoft's [VS Code Codicons](https://github.com/microsoft/vscode-codicons),
  via React Icons 5.5.0, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Resized and colored white for this button.
- Linux server: [Feather](https://feathericons.com/) server icon, MIT license below.
- Dokploy: platform logo reused from the Grovs documentation site.
- Easypanel: [official logomark](https://easypanel.io/img/logomark.svg), reused
  from the Grovs documentation site; [brand assets](https://easypanel.io/brand).

Logos identify their respective platforms and remain subject to their owners'
trademark policies. Buttons link to launch flows or setup instructions and do
not indicate marketplace approval.
